## Как печатать (для копицентра)

1. **Масштаб 100% (фактический размер).** Не «вписать в страницу» и не «по размеру листа»: монетки и кружки должны совпасть по размеру.
2. **Цветная печать**, односторонняя.
3. Первая страница первого файла — контрольная полоска: она должна быть ровно **50 мм**.
4. Резать не нужно — вырезаем сами.
