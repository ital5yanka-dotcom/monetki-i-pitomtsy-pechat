## Для копицентра — для всех файлов

- **Цветная печать, масштаб 100%** (фактический размер). Не «вписать в страницу» и не «по размеру листа».
- Резать не нужно — вырежем сами.

1. **Файл 1 первым.** Внизу первой страницы — чёрная полоска: она должна быть ровно **50 мм**. Тогда масштаб верный.
2. **Файл 3 — карты, двусторонняя печать.** В файле лист лиц и сразу за ним его оборот (10 листов). Сначала **один пробный лист** (первые 2 страницы): на просвет крестики в углах лица и оборота должны совпасть. Переворачивать можно по любому краю. Запас 3 мм: сдвиг 1–2 мм не виден.
3. **Файл 4 — папка** только на листе **SRA3**, не уменьшать до A3. Биговка по пунктирным линиям сгиба.
4. **Файл 6 — поле** одним листом **A3**, поля 7–10 мм по краям остаются белыми.
